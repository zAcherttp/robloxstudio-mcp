Module 1

SetupCài đặt

40 min

Claude Code running, the MCP built from source, and Studio's plugin panel showing Connected. Most of the time is downloads.

Why build from source? The npm package @chrrxs/robloxstudio-mcp is upstream's build, not this fork, and npx …@latest runs whatever was published last on every launch. A clone runs code you can read, updated when you choose.

1.1 Install Claude Code

Claude Code chạy được, MCP được build từ mã nguồn, và panel plugin trong Studio hiện Connected. Phần lớn thời gian là chờ tải.

Vì sao build từ mã nguồn? Gói npm @chrrxs/robloxstudio-mcp là bản của upstream, không phải bản fork này, và npx …@latest chạy bản mới nhất vừa được publish mỗi lần khởi động. Clone về thì bạn chạy đúng code mình đọc được, và chỉ cập nhật khi bạn muốn.

1.1 Cài Claude Code

Terminal
curl -fsSL https://claude.ai/install.sh | bash
PowerShell
irm https://claude.ai/install.ps1 | iex

Run claude once and sign in. The Claude desktop app's Code tab uses the same MCP settings.

Chạy claude một lần và đăng nhập. Tab Code trong app Claude trên desktop dùng chung cấu hình MCP.

1.2 Build the MCP1.2 Build MCP

Terminal
mkdir -p ~/dev && cd ~/dev
git clone https://github.com/zAcherttp/robloxstudio-mcp.git
cd robloxstudio-mcp
npm install
npm install --prefix studio-plugin
npm run build
npm run build:plugin
PowerShell
mkdir C:\dev -Force; cd C:\dev
git clone https://github.com/zAcherttp/robloxstudio-mcp.git
cd robloxstudio-mcp
npm install
npm install --prefix studio-plugin
npm run build
npm run build:plugin

npm run build:plugin also copies the plugin into Studio's Plugins folder (~/Documents/Roblox/Plugins on macOS, %LOCALAPPDATA%\Roblox\Plugins on Windows). Optional: npm test should end green; it never opens Studio.

npm run build:plugin cũng tự chép plugin vào thư mục Plugins của Studio (~/Documents/Roblox/Plugins trên macOS, %LOCALAPPDATA%\Roblox\Plugins trên Windows). Tuỳ chọn: npm test nên chạy xanh hết; lệnh này không mở Studio.

1.3 Register it with Claude Code1.3 Đăng ký với Claude Code

Absolute path to your clone; --scope user makes it available in every project.

Dùng đường dẫn tuyệt đối tới thư mục clone; --scope user để dùng được trong mọi project.

Terminal
claude mcp add robloxstudio --scope user -- node ~/dev/robloxstudio-mcp/packages/robloxstudio-mcp/dist/index.js --auto-install-plugin
PowerShell
claude mcp add robloxstudio --scope user -- node C:/dev/robloxstudio-mcp/packages/robloxstudio-mcp/dist/index.js --auto-install-plugin

--auto-install-plugin re-copies your local plugin build when Studio's copy is missing or older. It never downloads anything. Check with claude mcp list.

--auto-install-plugin chép lại bản plugin bạn build khi Studio thiếu hoặc đang giữ bản cũ hơn. Nó không tải gì từ mạng. Kiểm tra bằng claude mcp list.

1.4 Studio

  • Fully quit and reopen Studio; plugins load only at start. Open a Baseplate.
  • Plugins → MCP Server. It says Connected while claude is running.
  • If Studio asks whether the plugin may reach localhost or inject scripts, allow it.
  • The panel's bottom line shows the plugin's and the server's build stamp. Amber means they differ: rebuild both, restart both.
  • Thoát hẳn Studio rồi mở lại; plugin chỉ được nạp lúc khởi động. Mở một Baseplate.
  • Plugins → MCP Server. Panel hiện Connected khi claude đang chạy.
  • Nếu Studio hỏi plugin có được truy cập localhost hay chèn script không, hãy cho phép.
  • Dòng cuối panel hiện build stamp của plugin và của server. Màu vàng nghĩa là hai bản khác nhau: build lại cả hai, khởi động lại cả hai.
macOS screenshots need Screen Recording permission for the app that launched the server — your terminal or the Claude app: System Settings → Privacy & Security → Screen & System Audio Recording, then restart that app. The first screenshot after each start takes ~25 s while a helper compiles.
Chụp màn hình trên macOS cần quyền Screen Recording cho app đã khởi động server (terminal của bạn hoặc app Claude): System Settings → Privacy & Security → Screen & System Audio Recording, rồi khởi động lại app đó. Ảnh đầu tiên sau mỗi lần khởi động mất khoảng 25 giây để biên dịch helper.

Module 2

First contactLàm quen

30 min

Watch the agent read a place, change it, playtest it and look at it. Read the tool calls, not only the answers — that is the skill here. Use a throwaway Baseplate.

Xem agent đọc một place, sửa nó, playtest và nhìn nó. Hãy đọc các lệnh gọi tool chứ không chỉ câu trả lời, đó chính là kỹ năng cần học. Dùng một Baseplate để thử, hỏng cũng không sao.

ReadĐọc

Describe this place: what services have children, what is in Workspace, and whether there are any scripts.

Mô tả place này: service nào có con, trong Workspace có gì, và có script nào không.

get_project_structure, search_objects, get_instance_properties — read-only.chỉ đọc.

Build in edit modeBuild trong edit mode

In Workspace, make a 10×1×10 anchored neon platform 20 studs above the spawn, and a Script that makes it slowly change colour through the rainbow. Keep the script short.

Trong Workspace, tạo một platform neon 10×1×10, anchored, cao hơn điểm spawn 20 stud, và một Script làm nó đổi màu chậm theo cầu vồng. Viết script ngắn thôi.

Edit-mode changes undo with Ctrl/Cmd+Z in Studio.

Thay đổi trong edit mode có thể hoàn tác bằng Ctrl/Cmd+Z trong Studio.

Playtest and read backPlaytest và đọc lại

Start a solo playtest. Check the output for errors, and tell me the platform's colour twice, a second apart, from the server. Then stop the playtest and confirm it stopped.

Bắt đầu solo playtest. Kiểm tra output xem có lỗi không, và đọc màu của platform từ server hai lần, cách nhau một giây. Sau đó dừng playtest và xác nhận là đã dừng.

solo_playtest, get_runtime_logs, eval_server_runtime. Two different colours prove the script runs. Edit mode and a playtest are different DataModels: execute_luau without a target cannot see the running game.

solo_playtest, get_runtime_logs, eval_server_runtime. Hai màu khác nhau chứng minh script đang chạy. Edit mode và playtest là hai DataModel khác nhau: execute_luau không có target thì không thấy được game đang chạy.

Look at itNhìn kết quả

Start a playtest again, frame the platform, and take a screenshot.

Bắt đầu playtest lại, căn camera vào platform và chụp màn hình.

Break it on purposeCố tình làm hỏng

Change the script so it errors after 3 seconds. Playtest, find the error in the logs, fix it, and prove it is fixed.

Sửa script để nó báo lỗi sau 3 giây. Playtest, tìm lỗi trong log, sửa nó, và chứng minh là đã sửa xong.

That is the loop for the rest of the day: change → run → read back → decide.

Đây là vòng lặp cho cả buổi: sửa → chạy → đọc lại → quyết định.

Module 3

Trust, but verifyTin, nhưng phải kiểm

30 min

"Done" is what the agent believes. A value read back from the running game is what is true. Make asking for the number a reflex.

"Xong rồi" là điều agent tin. Một giá trị đọc lại từ game đang chạy mới là sự thật. Hãy tập thói quen luôn đòi xem số liệu.

Claims versus readbacksLời khẳng định và số liệu đọc lại

Add a part that launches a player upward when they touch it. Then prove it works without me playing.

Thêm một part bắn người chơi lên cao khi họ chạm vào. Sau đó chứng minh nó hoạt động mà không cần mình chơi thử.

A good answer starts a playtest, moves the character onto the pad from the server, reads its height back on the client several times, and reports the peak. A weak answer describes the code. If it walks the character from the client, nothing moves: the control script rewrites Humanoid.MoveDirection every frame.

Câu trả lời tốt sẽ bắt đầu playtest, di chuyển nhân vật lên pad từ phía server, đọc lại độ cao ở phía client vài lần, và báo độ cao tối đa. Câu trả lời yếu chỉ mô tả code. Nếu nó cho nhân vật đi từ phía client thì sẽ không có gì chuyển động: control script ghi đè Humanoid.MoveDirection mỗi frame.

Arm, trigger, read

A launch is over in half a second; one read afterwards misses it. Arm a sampler on the client that keeps the peak in _G, trigger from the server, read the peak back.

Một cú bắn kết thúc trong nửa giây; đọc một lần sau đó sẽ bỏ lỡ. Cài sẵn (arm) một bộ lấy mẫu ở client giữ giá trị lớn nhất trong _G, kích hoạt (trigger) từ server, rồi đọc (read) lại giá trị đó.

Measure the launch pad's peak height with an arm–trigger–read probe, three times.

Đo độ cao tối đa của launch pad bằng probe arm–trigger–read, ba lần.

Three numbers that roughly agree are a measurement. Three identical to the decimal usually mean the trigger never landed.

Ba con số gần giống nhau là một phép đo. Ba con số giống hệt đến từng chữ số thập phân thường có nghĩa là trigger chưa hề chạy.

Give each feature a way inCho mỗi tính năng một lối vào

One function per feature, Studio-only, calling the same server code as player input. Not a framework — a door the agent can open.

Mỗi tính năng một hàm, chỉ chạy trong Studio, gọi đúng đoạn code server mà input của người chơi gọi. Không phải framework, chỉ là một cánh cửa để agent mở.

Luau
-- ServerScriptService/DebugCommands
if not game:GetService("RunService"):IsStudio() then return end
_G.Debug = {
	launch = function(player)
		return LaunchPad.launch(player.Character) -- the same call the Touched handler makes
	end,
}

Traps worth knowing by nameNhững cái bẫy nên nhớ tên

  • A write to a property the engine owns reverts within a frame (Motor6D.Transform, LocalTransparencyModifier). Write, wait a frame, read back.
  • Studio caches require: an edited ModuleScript can return its old table even after a restart. Require a clone.
  • An eval longer than ~30 s times out and keeps running with its result lost. task.spawn it, poll _G.
  • solo_playtest stop has reported success while the game ran on. Check status.
  • Changing one attribute resends every attribute on that instance.
  • Ghi vào một property mà engine quản lý sẽ bị trả về trong vòng một frame (Motor6D.Transform, LocalTransparencyModifier). Ghi, chờ một frame, rồi đọc lại.
  • Studio cache require: một ModuleScript vừa sửa vẫn có thể trả về table cũ, kể cả sau khi khởi động lại. Hãy require một bản clone.
  • Một lệnh eval dài hơn khoảng 30 giây sẽ timeout nhưng vẫn chạy tiếp và mất kết quả. Dùng task.spawn, rồi hỏi lại _G.
  • solo_playtest stop từng báo thành công trong khi game vẫn chạy. Kiểm tra lại bằng status.
  • Đổi một attribute là gửi lại toàn bộ attribute của instance đó.

All of these, one line each, come from get_project_lessons. The long form with measurements is the agent guide.

Tất cả những điều này, mỗi điều một dòng, có trong get_project_lessons. Bản đầy đủ kèm số liệu đo đạc nằm trong hướng dẫn cho agent.

An agent cannot judge feel, readability at a glance, or a real phone in someone's hand. It brings you numbers and a screenshot; the call is yours.
Agent không đánh giá được cảm giác chơi, việc nhìn qua có hiểu ngay không, hay trải nghiệm trên một chiếc điện thoại thật. Nó mang về số liệu và ảnh chụp; quyết định là của bạn.

CLAUDE.md — how this game is built, run and checkedgame này được build, chạy và kiểm tra thế nào

Read at the start of every session, so keep it short. It answers: what the game is in two sentences; how code reaches Studio; how the agent drives a feature without clicking; how a change is verified; what it must never do. Template: templates/CLAUDE.md.

File này được đọc ở đầu mỗi phiên, nên hãy viết ngắn. Nó trả lời: game là gì (hai câu); code vào Studio bằng cách nào; agent điều khiển một tính năng mà không cần click ra sao; một thay đổi được kiểm chứng thế nào; và những gì tuyệt đối không được làm. Mẫu: templates/CLAUDE.md.

Small, with a rule you can check: a coin that adds to a leaderstat, a door that opens for one team, a round timer.

Nhỏ thôi, có một quy tắc kiểm tra được: đồng xu cộng điểm vào leaderstat, cánh cửa chỉ mở cho một team, đồng hồ đếm giờ cho mỗi round.

Skills

For depth on one topic — input, streaming, analytics, purchases — start with Roblox's own skills: ask Claude to run get_roblox_skills. Of the community packs, gamedev-skills checked out as accurate; roblox-skills.md has the details and the one to avoid.

Khi cần đi sâu một chủ đề (input, streaming, analytics, mua bán), hãy bắt đầu với skill của chính Roblox: bảo Claude chạy get_roblox_skills. Trong các bộ skill cộng đồng, gamedev-skills đã được kiểm tra là chính xác; roblox-skills.md có chi tiết, kèm bộ nên tránh.

Habits that payNhững thói quen đáng giữ

  • One task per session. A fresh claude for an unrelated task.
  • Plan first on anything bigger than a function: "plan it, don't write code yet".
  • Commit before a big change, so undo is git checkout.
  • Say what "done" means: the number you want, the screenshot you want.
  • Never paste secrets — Open Cloud keys, cookies — into a prompt or CLAUDE.md.
  • Mỗi phiên một việc. Việc không liên quan thì mở claude mới.
  • Lên kế hoạch trước với mọi thứ lớn hơn một hàm: "lên kế hoạch, chưa viết code".
  • Commit trước khi thay đổi lớn, để hoàn tác chỉ là git checkout.
  • Nói rõ "xong" nghĩa là gì: con số bạn muốn thấy, ảnh chụp bạn muốn xem.
  • Không bao giờ dán bí mật (Open Cloud key, cookie) vào prompt hay CLAUDE.md.
